## Implementation scope

The source composition, photography, type, page content, API and submission IDs are unchanged. The current patch corrects interaction lifecycle and compositing:

- The residences scene pins at `bottom bottom` when its source composition is taller than the viewport, so the lower description is readable before the mask opens. Taller windows retain `top top`.
- Breakpoint changes do not replay already revealed text. Scroll-linked artwork settles with 0.6 s scrub, and fonts/load/pageshow refreshes are coalesced.
- Permanent `will-change` reservations were removed from the oversized masked sunset/architecture layers.
- The interior gallery decodes the requested image before crossfading over the previous opaque image. Rapid inputs keep only the last request. Hidden slides are inert; vertical scrolling and taps remain native, while horizontal swipe is captured and does not open the lightbox.
- Plan zoom preserves the visual center when the image is smaller than the viewport. The image remains centered at intermediate zoom; viewport resize returns to fit. Toolbar controls correctly disable at their zoom bounds.
- Dialog opening has a short transform/opacity entrance, reduced-motion gets no animation, and stable scrollbar space avoids layout shifts during scroll lock.
